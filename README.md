# ECG Analog Front-End Design and Simulation

This project explores the design and simulation of an analog front-end
for ECG signal acquisition and conditioning.

The goal is to amplify a low-amplitude differential ECG signal while
reducing baseline drift, high-frequency noise, and common-mode
interference.

## Planned Signal Chain

ECG input  
→ Differential amplification  
→ High-pass filtering  
→ Low-pass filtering  
→ Conditioned ECG output
